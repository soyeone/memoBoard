# 데스크톱 메모보드 (Desktop Memo Board)

바탕화면에 띄워두고 원하는 위젯(캘린더, Todo List, 집중 타이머, 사진 액자, 포스트잇, 시계 등)을 하단 독에서 자유롭게 끌어놓아 크기 및 위치를 조절하고 배치할 수 있는 프리미엄 글래스모피즘 위젯 메모보드 프로그램입니다.

---

## ✨ 주요 기능

### 1. 캔버스 & 자유 배치 시스템
- **하단 플로팅 독 (macOS 감성 Dock)**: 하단 독에서 아이콘을 잡고 보드 원하는 곳에 드래그 앤 드롭하면 해당 지점에 즉시 생성!
- **8방향 자유로운 크기 조절 (Resize)**: 상/하/좌/우 및 모든 모서리를 잡고 원하는 크기로 조절
- **자유로운 위치 이동 (Drag & Move)**: 헤더를 잡고 어디든 자유롭게 이동
- **그리드 스냅 (Grid Snap)**: 20px 단위로 깔끔하게 위젯 정렬
- **스마트 자동 정렬**: 하단 독의 '자동 정렬' 버튼 클릭 시 모든 위젯을 한눈에 깔끔한 바둑판 형태로 자동 정렬
- **Z-Index 레이어 관리**: 클릭한 위젯이 자동으로 가장 앞쪽으로 이동
- **위젯 고정 (Pin)**: 실수로 움직이지 않도록 핀 잠금 지원
- **위젯 접기 (Fold)**: 헤더만 남기고 본문을 접어 공간 절약

### 2. 기본 내장 위젯 라인업
- 📅 **캘린더 (Calendar)**: 월별 달력 네비게이션, 오늘 날짜 하이라이트 배지, 날짜 클릭 시 일정/메모 빠른 등록 및 닷(dot) 표시
- ✅ **Todo List**: 할 일 추가/수정/삭제, 완료 체크박스 및 취소선, 진행률 프로그레스 바(%), 탭 필터(전체/진행/완료)
- ⏱️ **집중 타이머 (Focus Timer)**: 뽀모도로(25분 집중), 짧은 휴식(5분), 긴 휴식(15분), 스톱워치, SVG 원형 링 애니메이션, 완료 시 맑은 차임벨 연주(Web Audio API 내장)
- 🖼️ **사진 액자 (Photo Frame)**: 이미지 파일 드래그&드롭, 파일 선택 업로드, **클립보드 스크린샷 붙여넣기(Ctrl+V)** 지원, 화면 맞춤 방식(Cover/Contain) 토글, 하단 캡션 메모
- 📝 **포스트잇 메모 (Sticky Note)**: 글자 크기 조절(A-, A, A+), 글자 수 카운터, 7가지 컬러 테마(옐로우, 스카이블루, 민트, 라벤더 등)
- 🕒 **디지털 & 아날로그 시계 (Clock)**: 실시간 시계, 날짜/요일 표시, 디지털(24H/12H) 및 정교한 아날로그 시계 뷰 전환

### 3. 바탕화면 최적화 기능
- **프레임리스 투명/글래스모피즘 디자인**: 불필요한 기본 창틀 없이 감성적인 데스크톱 위젯 보드 연출
- **화면 항상 위 고정 (Always-on-top)**: 상단 핀 아이콘 클릭 시 다른 창들 위에 계속 띄워둘 수 있음
- **상태 영구 저장 (LocalStorage)**: 위치, 크기, 위젯 내용이 실시간 자동 저장되어 껐다 켜도 그대로 유지
- **데이터 백업 / 복원**: JSON 파일로 내보내기 및 언제든 다시 불러오기 지원

## 🚀 실행 방법

### 방법 1. 간편 실행 (권장)
- 폴더 내 `run.bat` 파일을 더블 클릭하여 실행합니다.

### 방법 2. 콘솔에서 데스크톱 앱 실행
```bash
npm start
```

### 방법 3. 웹 브라우저로 바로 실행
- [index.html](file:///e:/01_PRJ/memoBoard/index.html) 파일을 더블 클릭하여 Chrome, Edge 등의 브라우저에서 바로 열 수 있습니다.
